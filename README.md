# MVJCE Space - Campus Events Management

MVJCE Space is a modern and interactive web application designed to manage, organize, and display college events at MVJ College of Engineering. The platform provides a centralized digital space where students, faculty, clubs, and organizers can explore upcoming events, manage event details, and access event information efficiently.

The application simplifies campus event management through a responsive interface, event filtering, status highlights, and browser-based data persistence.

## Live Demo

The application is deployed on Vercel.

Live Website: [https://mvjce-space.vercel.app/](https://mvjce-space.vercel.app/) 

## Features

* Create, update, and delete campus events

* Filter events by club, category, or date

* Highlight upcoming and ongoing events

* Responsive design for desktop and mobile devices

* Modern user interface with smooth animations

* Browser-based data storage using LocalStorage

* Centralized platform for viewing and managing campus events

## System Architecture

The application follows a component-based frontend architecture. Users interact with the React interface to create, update, delete, filter, and view events. Event data is managed through reusable components and stored in the browser's LocalStorage.

### Architecture Workflow

1. Users access the application through the React frontend.

2. The main application manages the event interface and user interactions.

3. Reusable components display event cards, lists, modals, and filters.

4. Users can create, edit, or delete event details through the event modal.

5. Event data is stored and retrieved using the browser's LocalStorage.

6. The event list updates based on user actions and applied filters.

7. Upcoming and ongoing events are displayed with appropriate status highlights.

## Usage

1. Create Event: Click the Create Event button to add a new campus event.

2. Edit Event: Select the edit icon on an event card to update event details.

3. Delete Event: Select the delete icon to remove an event.

4. Filter Events: Use the filter icon to open the filter drawer and filter events by club, category, or date.

5. View Event Status: Upcoming and ongoing events are automatically highlighted in the interface.
